# Zomato Clone (HTML & CSS Only)

A pixel-faithful, responsive clone of the **Zomato** home landing page built exclusively with **HTML5** and **CSS3** (no JavaScript).

## 🚀 Key Features

1. **Hero Section & Navigation:**
   - Translucent overlay with high-resolution food photography.
   - Top navigation bar ("Get the App", "Investor Relations", "Add restaurant", "Log in", "Sign up").
   - Brand logo typography with signature italicized styling.
   - Integrated dual-input search bar:
     - City/Locality selector with pin icon & drop caret.
     - Search input for restaurants, cuisines, and dishes.

2. **Feature Cards (Dining Options):**
   - **Order Online** (Home delivery)
   - **Dining** (Explore city venues)
   - **Live Events** (Festivals & concerts)
   - Hover zoom effects and elevation shadows.

3. **Curated Collections:**
   - 4-card photo grid with dark-gradient overlays.
   - Card badges ("Top Trending Spots", "Best Rooftop Places", "Newly Opened Eateries", "Authentic Flavours").
   - Responsive grid (4 columns on desktop, 2 on tablet, 1 on mobile).

4. **Popular Localities:**
   - Responsive grid of top city neighborhoods with live place counters and chevron indicators.
   - Clean hover states with subtle translation and shadow.

5. **Zomato App Showcase Banner:**
   - Pure CSS mobile smartphone mockup previewing the app interface.
   - Custom styled radio selectors (Email / Phone).
   - "Share App Link" action form.
   - Google Play and Apple App Store download badges.

6. **Interactive FAQ / Explore Options (Pure CSS):**
   - Built using semantic `<details>` and `<summary>` elements with animated pure CSS rotating chevrons.
   - Sections for Popular Cuisines, Restaurant Types, Chains, and Cities.

7. **Footer:**
   - Multi-column directory (About Zomato, Zomaverse, For Restaurants, Learn More, Social Links).
   - Country and language selectors.
   - Social media buttons and copyright disclaimer.
